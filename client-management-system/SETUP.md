# מערכת ניהול לקוחות - עורך דין תעבורה
## הוראות התקנה ושימוש

### שלב 1: יצירת הפרויקט
1. היכנס ל-Google Drive ולחץ על **"חדש" > "Google Sheets"**
2. שנה את שם הגיליון ל: `מערכת ניהול לקוחות - תעבורה`
3. לחץ על **"תוספים" > "Apps Script"**

### שלב 2: העתקת הקבצים
בעורך Apps Script:

1. **Code.gs** - מחק את הקוד הקיים והדבק את תוכן הקובץ `Code.gs`
2. לחץ על **"+"** ליד "קבצים" ובחר **"HTML"**, קרא לו `Index` - הדבק את תוכן `Index.html`
3. צור קובץ HTML נוסף בשם `Styles` - הדבק את תוכן `Styles.html`
4. צור קובץ HTML נוסף בשם `JavaScript` - הדבק את תוכן `JavaScript.html`

### שלב 3: אתחול המערכת
1. שמור את כל הקבצים (Ctrl+S)
2. חזור לגיליון ה-Google Sheets
3. רענן את הדף (F5)
4. יופיע תפריט **"מערכת ניהול"** - לחץ עליו
5. בחר **"אתחול ראשוני של המערכת"**
6. אשר את ההרשאות הנדרשות

### שלב 4: הגדרת התראות
1. בתפריט **"מערכת ניהול"** > **"הגדר התראות אוטומטיות"**
2. ההתראות ישלחו אוטומטית:
   - **07:00** - תזכורת בוקר (דיונים היום + משימות באיחור)
   - **20:00** - סיכום יומי (דיונים ב-7 ימים + סטטיסטיקות)

### שלב 5: שימוש במערכת
- **סרגל צד**: תפריט "מערכת ניהול" > "פתח מערכת ניהול"
- **חלון מלא**: תפריט "מערכת ניהול" > "פתח דשבורד מלא"

---

## אפשרות נוספת: פריסה כאפליקציית ווב

1. ב-Apps Script לחץ על **"פריסה" > "פריסה חדשה"**
2. בחר **"אפליקציית ווב"**
3. הגדרות:
   - תיאור: "מערכת ניהול לקוחות"
   - הפעל כ: "אני"
   - גישה: "רק אני" (או כל מי שיש לו את הקישור)
4. לחץ **"פרוס"** וקבל קישור לאפליקציה

## מבנה המערכת

### גיליונות (נוצרים אוטומטית):
| גיליון | תוכן |
|---------|-------|
| לקוחות | שם, ת.ז., טלפון, אימייל, כתובת, הערות |
| תיקים | מספר תיק, לקוח, עבירה, בית משפט, סטטוס, שכ"ט |
| דיונים | תאריך, שעה, לקוח, תיק, בית משפט, אולם, סוג |
| משימות | תיאור, תיק, תאריך יעד, עדיפות, סטטוס |

### תכונות:
- **דשבורד** - תצוגה מרכזית של כל הנתונים החשובים
- **ניהול לקוחות** - הוספה, עריכה, מחיקה
- **ניהול תיקים** - עם קישור ללקוחות
- **ניהול דיונים** - עם אינטגרציה ליומן Google
- **ניהול משימות** - עם עדיפויות ומעקב סטטוס
- **התראות אוטומטיות** - מייל בוקר וערב
- **חיפוש גלובלי** - חיפוש לקוחות ותיקים
- **תמיכה מלאה בעברית** - RTL, ממשק בעברית
